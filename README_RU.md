### 💡 Что такое GerehGosha? (Важное разъяснение)

> [!IMPORTANT]
> **GerehGosha — это НЕ отдельная панель управления VPN и НЕ генератор готовых клиентских VLESS/VMess конфигураций «из коробки».**

**GerehGosha представляет собой специализированную инфраструктурную утилиту маршрутизации и оркестратор многолокационного исходящего трафика (Routing Utility)**. Утилита в режиме реального времени находит и поддерживает стабильные, низколатентные международные цепочки луковой сети, предоставляя чистые изолированные локальные SOCKS5-порты (`9050+`) для каждой выбранной страны.

Её ключевая возможность — **«Автоматическая инъекция (Injection)»**: в один клик через API утилита регистрирует эти многостраничные исходящие шлюзы напрямую в ваших основных панелях управления (таких как **PasarGuard**) в виде готовых Inbound-портов и хостов. Это даёт возможность операторам панелей мгновенно использовать чистые международные локации внутри своих клиентских конфигураций без ручной возни с маршрутизацией.

#### 🔌 Совместимость с панелями и планы развития:
* ✅ **PasarGuard:** Полная поддержка с автоматической инъекцией Inbound/Host в один клик через Admin API.
* 🔄 **x-ui / 3X-UI:** *В активной разработке* (модуль автоматической инъекции Inbound и правил маршрутизации скоро появится).
* 🔄 **Marzban:** *В активной разработке* (пайплайн подключения нод и исходящих шлюзов находится на стадии тестирования).

### ⚠️ Важные рекомендации по выбору хостинга (Обязательно к прочтению!)

Для обеспечения максимальной скорости, стабильности и отсутствия разрывов соединений в GerehGosha критически важно расположение сервера и политика провайдера:

* ❌ **Провайдеры с жесткими лимитами и фильтрацией пакетов:**  
  Серверы в **Hetzner**, **OVH** и **DigitalOcean** часто применяют жесткие ограничения частоты пакетов (rate-limit) и агрессивную фильтрацию многоузлового трафика, что приводит к нестабильности, потерям пакетов и постоянным таймаутам.

* ✅ **Протестированные и рекомендуемые платформы:**  
  GerehGosha неоднократно протестирована и демонстрирует превосходную, стабильную и плавную работу на облачных серверах **Railway**, **Play2Go**, **Fly.io**, **Vultr** и **Linode / Akamai**.

### ✨ Ключевые возможности

* 🌐 **Живое сканирование и автообнаружение:** Постоянный мониторинг и выбор здоровых международных реле с минимальной задержкой.
* ⚡ **Параллельные выходы для нескольких стран:** Одновременная работа нескольких изолированных локаций (США, Германия, Нидерланды, Великобритания и др.) на выделенных локальных портах (`9050`, `9051` и т.д.).
* 💉 **Инъекция в PasarGuard в 1 клик:** Автоматическое создание Inbound и сопутствующих параметров в панели PasarGuard без ручного редактирования конфигов.
* 🔄 **Мгновенная смена IP («New IP»):** Автоматическое определение ухудшения маршрута и смена выходного IP-адреса и цепочки нажатием одной кнопки.
* 🛡️ **Защищенный шлюз с веб-панелью:** Легковесный адаптивный веб-интерфейс с сохранением сессий в SQLite, переключением 4 языков (английский, персидский, русский, китайский) и управлением администраторами.
* 💻 **Интерактивная консоль (CLI):** Системная команда `gerehgosha` для простого управления службами, диагностики и восстановления учетных данных.
* 🚀 **Бесшовное обновление без потери данных:** Команда `gerehgosha update` обновляет исходный код из Git без сброса паролей и сохраненных настроек.

### 🚀 Быстрый запуск и установка

#### 1. Быстрая установка одной командой (Linux / Продакшен)
Скопируйте и выполните одну команду в терминале сервера от имени root:
```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirmarandidev/GerehGosha/master/gerehgosha.sh)" @ install
```
> 💡 **Полезные команды:** Через эту же строку можно выполнять обновление или удаление:
> - **Обновление:** `sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirmarandidev/GerehGosha/master/gerehgosha.sh)" @ update`
> - **Удаление:** `sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirmarandidev/GerehGosha/master/gerehgosha.sh)" @ uninstall`

#### Альтернатива: Ручное клонирование из Git
```bash
git clone https://github.com/amirmarandidev/GerehGosha.git /opt/gerehgosha
cd /opt/gerehgosha
sudo bash install.sh
```

#### 2. Windows (Для тестов и разработки)
Запустите командный файл:
```cmd
run_windows.bat
```

### ❓ Часто задаваемые вопросы (FAQ)

* ❓ **Можно ли подключать клиентов напрямую к GerehGosha?**  
  GerehGosha поднимает локальные SOCKS5-прокси на портах `9050+`. Вы можете направлять локальные приложения на эти порты, однако основное назначение утилиты — инъекция в панели вроде **PasarGuard**, чтобы они выступали исходящими шлюзами внутри ваших VLESS/VMess конфигураций.
* ❓ **Забыл пароль от панели управления:**  
  Выполните на сервере `python3 /opt/gerehgosha/gerehgosha-cli.py --show-credentials`, чтобы увидеть актуальные логин и пароль.
* ❓ **Удалятся ли настройки при обновлении?**  
  Нет; утилита `gerehgosha update` автоматически создает резервную копию `auth.db` и файлов конфигурации перед загрузкой свежего кода.
* ❓ **Как посмотреть логи в реальном времени?**  
  Используйте команду `journalctl -u gerehgosha.service -f` (Gateway) или `journalctl -u tor-checker.service -f` (Engine).

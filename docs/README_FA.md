### 💡 گره‌گشا دقیقاً چیه و به چه دردی می‌خوره؟

> [!IMPORTANT]
> **اول از همه حواستون باشه: گره‌گشا یه پنل کاربری مستقل یا سامانه فروش کانفیگ آماده (مثل VLESS یا VMess مستقیم) نیست که روی سرور نصبش کنید و بهتون لینک سابسکریپشن بده!**

در واقع، **گره‌گشا یه ابزار زیرساختی و کمکی برای مسیریابی و ایجاد خروجی‌های چندکشوره‌ست (Routing Utility)**. کارش اینه که مدام تو شبکه پیازی می‌چرخه، رله‌های تمیز، کم‌پینگ و پرسرعت رو برای کشورهای مختلف پیدا می‌کنه و خروجی هر کشور رو روی یه پورت ساکس محلی مستقل (`9050`، `9051` و...) بهتون تحویل میده.

قابلیت اصلی و باحال گره‌گشا **«تزریق مستقیم (Injection)»** هست؛ یعنی با یه کلیک و از طریق API، تمام این لوکیشن‌ها رو به صورت خودکار به عنوان Inbound و Host به پنل اصلی‌تون (فعلاً **پاسارگارد / PasarGuard**) اضافه می‌کنه. اینطوری می‌تونید توی کانفیگ‌های اصلی که دست کاربر میدید، چندین لوکیشن تمیز و خروجی پایدار داشته باشید، بدون اینکه لازم باشه دستی با پورت‌ها و روتینگ سر و کله بزنید.

#### 🔌 وضعیت پشتیبانی از پنل‌ها:
* ✅ **پاسارگارد (PasarGuard):** کاملاً متصل و هماهنگ؛ تزریق خودکار Inbound و Hostها تنها با یک کلیک از طریق توکن ادمین.
* 🔄 **پنل‌های x-ui و 3X-UI:** *در دست توسعه* (سیستم تزریق اینباند و روتینگ خودکار به‌زودی اضافه میشه).
* 🔄 **مرزبان (Marzban):** *در دست توسعه* (اتصال اوتباندها و نودهای مجزا در حال تست و پیاده‌سازیه).

### ⚠️ نکته مهم درباره انتخاب سرور (قبل از راه‌اندازی حتماً بخونید!)

برای اینکه از **گره‌گشا** نهایت سرعت و پایداری رو بگیرید و درگیر کندی یا تایم‌اوت نشید، سروری که انتخاب می‌کنید خیلی مهمه:

* ❌ **سرورهایی که محدودیت دارن و اذیت می‌کنن:**  
  دیتاسنترهایی مثل **هتزنر (Hetzner)**، **OVH** و **DigitalOcean** به خاطر ریت‌لیمیت‌ها و سخت‌گیری‌هایی که روی ترافیک پیازی دارن، کیفیت ثابتی نمیدن و ممکنه باعث افت سرعت یا قطعی‌های مکرر بشن.

* ✅ **سرورها و پلتفرم‌های تست‌شده و عالی:**  
  این ابزار روی سرورهای ابری **Railway** و **Play2Go** (و همین‌طور **Fly.io**، **Vultr** و **Linode / Akamai**) بارها تست شده و کارایی فوق‌العاده نرم، پایدار و با پهنای باند بالایی داره.

> 💬 **یه کلام رفاقتی:**  
> این پروژه قراره روزبه‌روز بهتر بشه! موتور روتینگ، مصرف رم و متدهای بررسی سلامت شبکه مدام در حال بهینه‌سازیه تا بالاترین پایداری رو تجربه کنید. خیالتون از بابت آپدیت‌ها راحت باشه، فقط سرور رو درست انتخاب کنید و بقیه‌شو بسپارید به گره‌گشا.

### ✨ قابلیت‌های کلیدی

* 🌐 **اسکن زنده و کشف خودکار:** پیدا کردن رله‌های سالم و پرسرعت بین‌المللی با بررسی لحظه‌ای لتنسی و پینگ.
* ⚡ **خروجی همزمان چند کشوره (Multi-Exit):** اجرای همزمان لوکیشن‌های مختلف (آمریکا، آلمان، هلند، انگلیس و...) روی پورت‌های مجزا و ایزوله.
* 💉 **تزریق مستقیم به پاسارگارد:** ساخت خودکار Inbound و کانفیگ‌های متناظر با هر کشور توی پنل PasarGuard فقط با یه کلیک و بدون نیاز به دستکاری دستی کانفیگ‌ها.
* 🔄 **دریافت آی‌پی جدید (New IP):** تشخیص افت کیفیت مسیر و تعویض درجا و سریع آی‌پی خروجی با یه دکمه.
* 🛡️ **داشبورد سبک، امن و ۴ زبانه:** پنل وب سریع با پایگاه داده SQLite، قابلیت سوییچ بین ۴ زبان (فارسی، انگلیسی، روسی، چینی) و مدیریت مشخصات ادمین.
* 💻 **کنسول ترمینال اختصاصی (CLI):** دستور سیستمی `gerehgosha` برای مدیریت آسان سرور، عیب‌یابی و دیدن مشخصات ورود.
* 🚀 **آپدیت هوشمند بدون پریدن اطلاعات:** دستور `gerehgosha update` برای گرفتن آپدیت‌های تازه بدون اینکه دیتابیس ادمین‌ها یا تنظیمات ذخیره‌شده پاک بشه.

### 🚀 نصب و راه‌اندازی سریع

#### ۱. نصب فوری با یک خط دستور (لینوکس / سرور اصلی)
فقط کافیه این یه خط دستور رو کپی کنید و توی ترمینال سرورتون (با دسترسی روت) اینتر بزنید:
```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirmarandidev/GerehGosha/master/gerehgosha.sh)" @ install
```
> 💡 **دم‌دستی و کاربردی:** برای آپدیت یا حذف هم می‌تونید از همین دستورات سریع استفاده کنید:
> - **آپدیت:** `sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirmarandidev/GerehGosha/master/gerehgosha.sh)" @ update`
> - **حذف کامل:** `sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/amirmarandidev/GerehGosha/master/gerehgosha.sh)" @ uninstall`

#### روش جایگزین: کلون دستی از گیت‌هاب
```bash
git clone https://github.com/amirmarandidev/GerehGosha.git /opt/gerehgosha
cd /opt/gerehgosha
sudo bash install.sh
```

#### ۲. محیط ویندوز (برای تست و توسعه)
کافیه فایل زیر رو اجرا کنید:
```cmd
run_windows.bat
```

### 🔑 پورت‌ها و درگاه‌های دسترسی

* 🌐 **داشبورد اصلی (Gateway):** `http://SERVER_IP:5000`
* ⚙️ **درگاه مستقیم انجین:** `http://SERVER_IP:54322`
* 🔌 **پورت‌های خروجی ساکس (SOCKS5):** `9050+` (به ترتیب کشورهای انتخابی اضافه میشه)
* 📁 **مسیر نصب روی سرور:** `/opt/gerehgosha`

> **دیدن مشخصات ورود:** هر وقت خواستید می‌تونید توی ترمینال سرور دستور `gerehgosha` رو بزنید و با انتخاب گزینه **Manage Admins**، مشخصات ورود رو ببینید یا تغییر بدید.

### 💻 دستورات خط فرمان (CLI)

با اجرای دستور `gerehgosha` توی ترمینال سرور، یه منوی تر و تمیز باز میشه:

```text
=====================================
    GerehGosha (گره‌گشا) Manager     
   Developed by Amir (@amirmarandidev) 
=====================================
1. Install All Services (Tor Engine & Gateway)
2. Manage Admins (Add/View users)
3. View System Logs (Gateway)
4. Restart Gateway Service
5. Restart GerehGosha Engine (Tor)
6. Update GerehGosha (Git Pull & Seamless Upgrade)
7. Fetch Pasarguard Token
8. Uninstall GerehGosha
9. Exit
=====================================
```

#### دستورات تک‌خطی و دم‌دستی:
* 🔄 **آپدیت بی‌دردسر:** `gerehgosha update`
* 🔑 **نمایش یوزر و پسورد ادمین:** `python3 /opt/gerehgosha/gerehgosha-cli.py --show-credentials`
* 🩺 **بررسی سلامت سیستم و پورت‌ها:** `python3 /opt/gerehgosha/gerehgosha-cli.py --status`
* 🧹 **خالی کردن کش و ریست مدارها:** `python3 /opt/gerehgosha/gerehgosha-cli.py --flush-cache`

### ❓ سوالات متداول

* ❓ **میشه کاربرها مستقیم به خود گره‌گشا وصل بشن؟**  
  گره‌گشا روی سرور پورت‌های ساکس محلی (`9050` به بالا) باز میکنه. هرچند برنامه‌های روی خود سرور می‌تونن ازش استفاده کنن، ولی هدف اصلی اینه که اون رو به پنل‌هایی مثل **پاسارگارد** تزریق کنید تا در قالب کانفیگ‌های اصلی به دست کاربرا برسه.
* ❓ **رمز پنل وب یادم رفته، چکار کنم؟**  
  توی ترمینال سرور دستور `python3 /opt/gerehgosha/gerehgosha-cli.py --show-credentials` رو بزنید تا یوزر و پسورد فعال رو نشونتون بده.
* ❓ **اگه پروژه رو آپدیت کنم، تنظیماتم میپره؟**  
  نه اصلاً؛ دستور `gerehgosha update` قبل از کشیدن کدهای جدید، از دیتابیس `auth.db` و کانفیگ‌ها بکاپ میگیره و بعد از آپدیت دست‌نخورده سر جاشون میذاره.
* ❓ **لاگ زنده سرویس‌ها رو چطوری ببینم؟**  
  برای گیت‌وی دستور `journalctl -u gerehgosha.service -f` و برای انجین دستور `journalctl -u tor-checker.service -f` رو بزنید.
